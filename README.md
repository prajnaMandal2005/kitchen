## ✨ Key Features

### 👥 Role-Based Ecosystem
- **Customer**: Browse a curated menu, customize selections, and track order history.
- **Chef**: Real-time kitchen dashboard for managing active orders and updating status.
- **Waiter**: Dedicated view for coordinating table service and order delivery.
- **Manager**: Comprehensive oversight of staff, inventory, and restaurant performance.

### 🔐 Secure & Modern
- **Multi-Factor Auth**: Secure registration powered by `OTP Verification` via email.
- **JWT Protection**: Robust authentication and Role-Based Access Control (RBAC).
- **Smooth Animations**: A fluid user experience powered by `Framer Motion`.
- **Responsive Design**: Elegant Material UI components optimized for all devices.
